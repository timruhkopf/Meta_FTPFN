| 2026-09-17 | [Registration as a learned stochastic transport: flow matching / SDE direction](2026-09-17-lupi-registration-sde-flow-matching-direction.md) | Design log, nothing implemented: proposes treating registration as a continuous path from B's raw `(x,y)` to its registered image, learned via conditional flow matching (simulation-free regression against a straight-line interpolant's velocity, no backprop through a solver) so `T` and `h` are recovered *jointly* by one mechanism instead of two separately-parameterized steps. New branch `lupi-registration-sde` carries this forward. |

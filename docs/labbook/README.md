| 2026-09-15 | [Quantile-normalization-under-A is structurally bottlenecked; a decoder-only, task-ID-tagged proposal](2026-09-15-quantile-normalization-bottleneck-and-decoder-only-proposal.md) | Colleague-verified rank-collapse (z_a_ctx exactly rank/(n_a+1)), a resolution cap independent of query count, a heatmap "artifact" that turned out to be the model correctly tracking the rank-collapsed staircase (not a bug), and a decisive B-blindness ablation (swapping B costs 0.75 nats, p=3.9e-10 — student mode is not B-blind) all converged on one meta-point: A's own ECDF cannot self-diagnose its own acquisition bias, so per-task quantile normalization under A is structurally bottlenecked, not just under-resolved. Logged three proposals: explicit "inpainting via B" as its own objective, shared-reference (not A's-own-ECDF) value normalization, and a simpler decoder-only task-ID-tagged architecture (oracle=[A,B_inA], student=[A,B raw+tag], CE distillation) — being built by a parallel session, coordinated via cross-session message. |

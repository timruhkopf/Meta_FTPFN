# Cross-Task PFN Distillation: Latent Unwarping for Sparse Target Tasks

This repository outlines a novel architecture inspired by latent-action / JEPA-style distillation models (
referencing [arXiv:2602.10098](https://arxiv.org/pdf/2602.10098)), adapted for Prior-Data Fitted Networks (PFNs) in a
multi-task setting.

The core objective is to achieve highly calibrated Posterior Predictive Distributions (PPDs) for a sparse target
task ($A$) by leveraging a densely sampled, systematically distorted related task ($B$), without explicitly modeling the
uncertainty of the transformation.

## 1. Problem Statement

We operate in a multi-task learning setting with two distinct datasets:

* **Task A (Target):** Sparse data. We need to evaluate the posterior on $A_{test}$.
* **Task B (Source):** Densely sampled, but related to $A$ via an unknown but constrained distortion (e.g., shift,
  scale, invertible warp).

Standard PFN inference for Task A uses $[A_{test} \vert{} A_{train}]$. However, knowing $B$ should fundamentally improve
our belief over $A_{test}$. Because we control the generative prior and the class of distortions during training, we
mathematically know the "unwarped" optimal representation of $B$ in $A$'s space, denoted as $B_{in A}$.

**The Goal:** Train a model to automatically map $B \rightarrow \hat{B}_{in A}$ and use it to improve $A_{test}$
predictions, dynamically adjusting its confidence based on how well it can unwarp $B$, trained via distillation from an
Oracle teacher.

---

## 2. Architecture Design

The architecture utilizes **TabPFN v2.5** as the backend, capitalizing on its feature-wise in-context learning
capabilities to reason about the transformed spaces. The system consists of three main components: The Teacher, the
Latent VLA Encoder, and the Predictor.

### A. The Teacher (Oracle PFN)

* **Role:** Provides the optimal target distribution for distillation. Since both $A$ and the exact unwarped $B_{in A}$
  are known during the synthetic prior training, the teacher operates with perfect information.
* **Input:** $[A_{test} \vert{} A_{train}, B_{in A}]$
* **State:** Frozen (Inference mode). Pre-trained TabPFN.
* **Output:** The target Posterior Predictive Distribution (PPD). This anchors the training, ensuring the target is
  fundamentally valid from step one.

### B. The Latent "VLA" Encoder (Unwarping Branch)

* **Role:** Takes the dense, distorted dataset $B$ and maps it into the latent space of $A$, producing $\hat{B}_{in A}$.
* **Input:** Task $B$ tokens.
* **Mechanism:** It operates as a PFN branch. Instead of isolated processing, it utilizes **KV-cache splicing**. It
  cross-attends from $B$ to $A$'s KV-cache (generated by passing $A$ through a parallel PFN encoder) across all layers.
  This cross-attention allows the encoder to contextualize $B$'s distortion relative to $A$ and refine its
  representation.
* **Design Question / Variant:** *How to process B's internal structure?* We can either interleave
  this $B \rightarrow A$ cross-attention with $B \rightarrow B$ self-attention, or simply concatenate the KV cache to
  the existing $B$ context (which implicitly includes self-attention).

### C. The Predictor (Student PFN)

* **Role:** Generates the final calibrated PPD for $A_{test}$.
* **Input:** Raw $A_{train}$ tokens, raw $A_{test}$ tokens, and the refined $\hat{B}_{in A}$ representations from the
  VLA encoder. *(Note: We explicitly pass raw $A$ tokens here, not the self-attended output tokens from a student PFN).*
* **Mechanism:** Uses standard PFN-style self and cross-attention (not JEPA-style restricted attention among test
  tokens).
* **State:** Instantiated from the original pre-trained TabPFN checkpoint to warm-start the model.

---

## 3. Feature Space & Task Tokens

To help the model distinguish between the unwarped target space and the warped source space, we introduce learnable task
tokens directly in the feature space.

**Implementation (TabPFN v2.5 Native):**
Rather than breaking the pre-trained transformer architecture by injecting external latent tokens, we append a
categorical **Task ID** feature column to the input space:

* `0` for Task $A$ tokens
* `1` for Task $B$ tokens

Because TabPFN v2.5 supports feature-wise in-context learning, the embedding of this categorical feature acts
identically to a task token, allowing the model to smoothly convey and process uncertainty based on the data's origin.

---

## 4. Training Strategy & Objectives

The model is trained to implicitly unwarp $B$ and adjust its predictive confidence without explicit uncertainty
modeling. We achieve this via a two-phase, dual-objective training curriculum.

### Phase 1: VLA Initialization (L2 Warm-up)

Before stacking the Predictor on top, we pre-train the Latent VLA Encoder to close the gap between its output and the
known ideal state.

* **Objective:** L2 distance between the predicted tokens $\hat{B}_{in A}$ and the true unwarped tokens $B_{in A}$.
* **Alternative Objective:** NLL / Bar loss against the true $B_{in A}$ tokens. This way we can observe the model's
  confidence in its unwarping predictions explicitly.
* **Benefit:** Provides a strong initialization for the VLA module, ensuring the Predictor receives sensible inputs when
  end-to-end training begins. And we may observe, what the model actually thinks about B's unwarping, which is useful
  for debugging and understanding the model's behavior.

### Phase 2: End-to-End Distillation (KL Divergence)

Once the VLA is warm, we train the full Predictor pipeline.

* **Target Objective:** Minimize the Kullback-Leibler (KL) divergence between the Teacher's PPD and the Predictor's PPD
  for all $A_{test}$ tokens:

$$\mathcal{L} = D_{KL} \Big( P_{Teacher}(A_{test} \vert{} A_{train}, B_{in A}) \parallel P_{Predictor}(A_{test} \vert{} A_{train}, \hat{B}_{in A}) \Big)$$

* **Learning Rate Curriculum (Fade-in):**
* **Latent VLA Encoder:** Trained aggressively from the start.
* **Predictor:** Because it is initialized with a highly competent pre-trained TabPFN checkpoint, we fade in its
  learning rate slowly. This prevents catastrophic forgetting of its prior-fitting capabilities while it learns to
  integrate the newly unwarped $\hat{B}_{in A}$ tokens from the VLA stack.

---

## 5. Key Advantages of this Architecture

1. **Anchored Targets:** Because the Teacher uses the true $B_{in A}$ and a frozen, pre-trained PFN, the target KL
   distribution is guaranteed to be a valid, highly calibrated posterior from step one.
2. **Implicit Uncertainty:** The Predictor doesn't need a separate confidence head. By minimizing KL against a teacher
   that "knows" the true unwarped data, the student naturally learns to widen its distributions if the $B \rightarrow A$
   unwarping is ambiguous.
3. **Preserved Pre-training:** Utilizing raw $A$ tokens for the predictor and warm-starting with TabPFN weights ensures
   that standard in-context learning mechanics remain intact while cross-task reasoning is grafted on.
